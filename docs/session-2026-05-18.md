### 3. Tiered Event Marker Visualization

Replaced uniform event markers with three visual tiers keyed to magnitude, so landmark events stand apart from minor ones without removing smaller events.

| Tier | Magnitude | Symbol | Line | Label |
|------|-----------|--------|------|-------|
| **Landmark** | ≥ 7 | Diamond | Dashed, full height | Axis label shown |
| **Notable** | 4–6 | Circle | Solid, proportional height | No axis label |
| **Minor** | < 4 | Square tick | Short (14% chart height) | No label |

Opacity: 1.0 / 0.75 / 0.45 respectively.

Same-year events spread horizontally by `2.5 * dpr` per position so markers don't overlap.

---

### 4. Year-Cluster Click Navigation

Multiple events in the same year are now all accessible via a single click. ChartCanvas collects all events at the nearest year, sorts them by magnitude descending, and passes the full array to `EventDetailPanel`.

When a year has more than one event, the detail panel shows a navigator bar:
- Colored dot per event (color = direction)
- `← X / N →` arrows to step through
- Focused event displayed as full article lede below

Single-event years: no navigator shown, same lede layout.

**Key state:** `selectedYearEvents: Event[]` in `StratumView.jsx` replaces the prior single `selectedEventId`.

### 6. SCOTUS Composition Packet

New context layer implementing the `strip` packet type — a thin proportional bar rendered in the top padding area of the chart, showing Supreme Court ideological composition across 20 court eras from 1865 to 2026.

**Data (`src/data/packets/scotus-composition.json`):**
Each record: `{ start, end, conservative, swing, liberal, total, label }`.  
20 eras from Chase Court (1865) through Roberts Court supermajority (2020–2026).

**Rendering (`src/engine/packetRenderer.js` → `renderStripPacket`):**
- 8px tall bar sitting 10px above `PAD.top` (at canvas `y ≈ 12*dpr`)
- Each era rendered as three adjacent segments: red (conservative) | grey (swing) | blue (liberal), proportional to seat count out of 9
- Thin white separator line at left edge of each era
- "SCOTUS" label in DM Mono, right-aligned in the left margin

**Packet registry (`src/data/packets/registry.json`):** Added entry with type `strip`, time_range 1865–2026, legend entries for conservative/liberal/swing.

To use: open **Layers** tab in sidebar → toggle **SCOTUS Composition** on.

## Design Decisions Made

| Decision | Rationale |
|----------|-----------|
| NYT editorial aesthetic (light theme) | Positions Empath Graph as a serious journalistic tool, not a dashboard; legibility for facilitated workshops |
| Three magnitude tiers, not filtered | Minor events carry historical significance; visual hierarchy communicates importance without erasure |
| Year-cluster click, not separate markers | Keeps the chart clean; all events in a year are grouped because they share temporal context |
| Strip packet in top padding (not overlay) | Avoids obscuring data lines; SCOTUS context is ambient, not a primary data series |
| Internal component names unchanged | `StratumView.jsx`, `StratumView` etc. unchanged — rename scope was UI only, no structural churn |

- **Strip + band collision** — if both US Presidents and SCOTUS are active, the SCOTUS strip sits 10px above PAD.top; a second strip type would need a different offset. Stack offset not yet implemented.
- **2026 event verification** — the 2026 SCOTUS events were sourced from ChatGPT and have placeholder URLs. Source URLs should be verified before treating as canonical.
